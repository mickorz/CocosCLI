01

这是什么

What it is

cocoscli 是面向 Cocos Creator 3.7.x 的命令行工具。它把 CocosMCP（编辑器扩展）的能力封装成 7 条 CLI 命令，让 AI 和开发者不用再手动点编辑器，一条命令就能完成装扩展、开工程、构建打包、预览验证、编译检查。

以前手动操作

重复点编辑器菜单、手动装扩展、手动拷 mcp 配置、构建出错靠肉眼看日志、预览要自己开浏览器盯 console。

现在 cocoscli

一条命令跑通全流程，配置自动写好，编译检查自动出 log，预览验证带 30 秒超时兜底，环境不对精准报错。

02

核心理念

Core idea
把编辑器里散落的操作，收敛成可复现、可脚本化的命令。

每条调 CocosMCP 的命令背后，都跑通同一套四条链路前置检查。环境没准备好不会默默失败，而是精准指出卡在哪一步，让报错指向问题根因。

  • CocosMCP 已装（extensions/CocosMCP 存在）
  • CocosMCP 已 build（dist/tools/<tool>.js 存在）
  • MCP HTTP server 在跑（verifyMcpConnection）
  • 目标工具可用（调一次看响应结构）
03

七大命令

Seven commands
01
cocoscli init

装 CocosMCP + build + 写 mcp-server.json / opencode.json + 打开工程，默认免登录。

02
cocoscli open / close

打开或关闭工程；已开则跳过，close 精准杀对应 CocosCreator 进程。

03
cocoscli remove

卸载 CocosMCP：关工程 + 删扩展 + 清配置，一步干净。

04
cocoscli build <platform>

构建打包到 web-desktop / wechat / douyin 等指定平台。

05
cocoscli verify <scene>

验证：编译检查 + MCP/preview + opencode 预览场景，事件流监控。

06
cocoscli compile

编译检查（run_script_diagnostics）+ 生成 log，快速定位脚本错误。

04

核心能力

迁移自 CocosMCP
编译检查

调 cocos-mcp 的 run_script_diagnostics，扫脚本错误并生成 log，不用开编辑器就能查。

预览场景

MCP/preview + opencode 事件流监控，切场景加 30 秒超时兜底，避免一直挂着等。

读浏览器日志

经 cdp-cli 桥接 Chrome DevTools Protocol，拿预览页面的 console 输出。

场景与资源操作

经 CocosMCP 暴露的 HTTP 端点操作场景节点、组件、预制体与资源。

想接入 CocosMCP 的新能力？统一四步：读 SKILL 摸清端点，加 HTTP 函数，加命令，注册命令。新命令自动复用同一套四条链路前置检查。

  • 读 SKILL：.opencode/skills/<skill>/SKILL.md 摸端点 / 参数 / 返回
  • 加函数：utils/verify.ts 复用 httpPostJson / verifyMcpConnection
  • 加命令：commands/ 里四条链路 + 调用 + 输出
  • 注册：index.ts 用 commander 挂上
